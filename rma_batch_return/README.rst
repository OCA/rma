This module allows to transfer first the products in a picking in order
to populate an RMA batch.

Use Cases / Context
===================

In some flows where returning products is the first action and where a
lot of products could be returned at once, it is easier to start from a
blank picking and use a scan application to do the whole lines.

Configuration
=============

- Go to Inventory > Configuration > Operation types
- Choose the RMA receipt
- Check the 'Create RMA At Confirm' box.
- Select the default operation that will be used for RMA batch creation

Usage
=====

- Go to Inventory

- In the dashboard, choose the RMA receipts

- Create a blank picking and fill in the concerned partner.

- Fill the products (in the picking form or with your favorite barcode
  app).

- Validate the picking.

- Go to RMA batches and validate the flow as usual.

- Alternatively, you can start from RMA batch, create it and click on
  'Create Return'.

- A blank one will be created on the default picking type for RMA
  receipts.
